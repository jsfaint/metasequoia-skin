# 图片与动图

所有图片路径都是**包内相对路径**：纯 ASCII，只能含字母数字和 `./_-`，用 `/` 分层（如 `assets/paper.png`），不能有 `..`、不能以 `/` 开头、不能用 `\`、单段不能是 `.`，总长 ≤256 字节。

扩展名规则分两档：

- **v1 的装饰图与背景图**：靠系统图片解码器加载，PNG / JPEG / BMP / GIF / WebP 一般都能用，SVG 不支持；装了不认识的解码器或文件损坏就会画不出来。
- **v2 的面板图、挂件与工具栏图片模式**：只认 `.png` / `.apng` / `.gif` / `.webp`，SVG / JPG 会被 Server 直接拒收。

格式优先 PNG（含透明）。尺寸单位是 **DIP**（逻辑像素，随 DPI 缩放）。

## 装饰图 vs 背景图（v1）

| | 装饰图 `decoration` | 背景图 `background` |
|---|---|---|
| 位置 | 卡片**上方**一条独立区域，底边贴卡片顶边、不重叠 | 铺在卡片**里面**，底色之上、候选文字之下，按外框圆角裁剪 |
| 贴哪边 | `align`：left / center / right（默认 right） | 永远居中，靠 `fit` 决定怎么缩放 |
| 尺寸 | `top_inset_dip` × `width_dip` 的盒子，图片在盒内 `contain` 等比居中 | 由卡片大小决定，`fit` 取 cover（填满裁切）/ contain（完整显示）/ stretch（拉变形） |
| 压暗 | — | `opacity`：0.35 = 图叠在底色上留 35% 强度。它是往**当前主题的 `surface`** 混，不是往黑混；图自身带 alpha 时保持 1.0 才对，调小只会把它压掉 |

共同规则：

- **两张图都只有一份，不分明暗主题**（它们挂在 `[candidate_window]` 下，不在 `[candidate.dark]` / `[candidate.light]` 里）。所以一张图必须在两套主题下都成立，最稳的做法是只放「中性纹理 / 高光」——图自身带 alpha，颜色交给各主题的 `surface`；想深色下更亮、浅色下更淡只能靠 `opacity` 折中。
- 装饰图的**宽高比要和 `width_dip` / `top_inset_dip` 对得上**，否则盒内留白。
- 有装饰图时，候选框最小宽度会自动取 `max(160, min_width_dip, width_dip)`；`fit_content = true` 时那个 160 不再垫（按 0 算）。装饰图不会跑出卡片。
- 装饰图上叠加的候选词**不是图片**：它用候选字体画出来，字号由 `candidate_overlay_font_size_dip` 单独决定（这不是候选本体字号）。词太宽时会先缩到 `candidate_overlay_min_font_size_dip`，再宽就允许超出装饰框，不折行。

## 工具栏图片模式的图片

工具栏图片模式的背景图、按钮底图、按钮图与状态图只认四种扩展名，尺寸与摆放规则见 [toolbar-image-mode.md](toolbar-image-mode.md)。要点：

- 背景图必须同时给 `image_width_dip` / `image_height_dip`（屏幕 DIP），图片拉伸到这个尺寸；给 2 倍图时写像素的一半。
- 按钮底图画在 `background`，不要画进背景图，否则用户关掉按钮后底图还留在图上。
- 按钮图在按钮框里等比缩放；`images` 里缺某个状态时回落到 `image`，两者都没有时画内置矢量图标。

## v2 的图片

- **九宫格面板图**（`border_image.source` / `light_source`）：默认切成九块拉伸，所以四条切片线要画在纯纹理处；一般是一张大图（如 400×300），四角是完整的花纹 / 圆角。`repeat` 改平铺时按源图原尺寸一块块铺，适合可无限加长的花纹边框。扩展名只能是 `.png` / `.apng` / `.gif` / `.webp`。
- **竖排面板图**（`[candidate_window.border_image.vertical]`）：横竖排图尺寸不同就各写一套 `slice_dip`；`light_source` 不继承横排，竖排要浅色变体必须自己写。竖排面板比横排窄时，右 / 左边距通常也要用 `[candidate_window.content_insets_dip.vertical]` 单独收窄。
- **卡片外挂件**（`decorations[].image`）：扩展名同上，盒子由 `width_dip` / `height_dip` 给出。图片在框内 **contain 等比缩放、居中**，所以**盒子最好与图片宽高比一致**，比例差得多时四周会留白。
- **面板图也能放动图**，但一般建议用静态图，把动画留给挂件。

## 动图

v2 皮肤里的图片可以是动图——APNG、GIF，以及系统解码器能逐帧读出的动画 WebP，**原生播放，不用额外开关**。

- 帧时长按浏览器规则取（分母为 0 按 100 算，10 ms 及以下按 100 ms），循环次数按文件里的设置，播完停在最后一帧。
- 动画从候选窗出现时开始，同一次显示里打字不会让它重头开始；候选窗隐藏或换皮肤后，下一次显示从第一帧开始。
- 工具栏图片模式里的动图在工具栏隐藏或自动隐藏淡出后停止播放；窗口形状按所有帧合起来的轮廓裁，任何一帧画到的地方都不会被裁掉，也都能点到、能拖动。

**动图的边界**：

- 系统关掉「动画效果」（设置 → 辅助功能 → 视觉效果 → 动画效果）时只显示静态图（APNG 的默认图、GIF 首帧）。
- 一张动图超过 **1024 帧**或解码后超过 **64 MB**、文件损坏或不合规范时也只显示第一帧。
- 所有动图的帧合计受 **64 MB 显存预算**约束。

**v1 皮肤里的图片始终是静态首帧**，动图只在 `schema_version = 2` 且 `base = "canvas"` 的皮肤里播放。写了 `2` 但 `base` 不是 `canvas` 的皮肤按 v1 加载，同样只显示首帧。
